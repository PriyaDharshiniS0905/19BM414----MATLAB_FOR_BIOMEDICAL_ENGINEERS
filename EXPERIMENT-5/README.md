## EXPERIMENT 5: DISEASE CLASSIFICATION USING BIOMEDICAL DATASETS
## AIM:
To classify biomedical observations into disease classes using supervised machine learning.
## INPUT:
A CSV dataset with rows as samples, numerical biomedical predictors and one categorical class column named Disease. Example: biomedical_dataset.csv.
## INPUT FILE / PARAMETERS:
File name / Model: biomedical_satasets.csv
## THEORY / PRINCIPLE:
Biomedical classification uses measured features to predict predefined classes. This experiment demonstrates data cleaning, missing-value imputation, train/test separation, decision-tree training, prediction and performance evaluation.

## PROCEDURE:
1. Load and inspect the dataset.
2. Separate the disease label from predictors.
3. Select numerical predictors.
4. Impute missing values using the median.
5. Partition data into training and test sets.
6. Train a decision tree.
7. Predict the test set.
8. Calculate accuracy and class-wise metrics.
9. Display the confusion matrix and tree.
